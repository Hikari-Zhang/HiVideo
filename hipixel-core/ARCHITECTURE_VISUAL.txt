┌─────────────────────────────────────────────────────────────────────────────────┐
│ TILE-BASED INFERENCE (RealESRGANFilter reference pattern)                       │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  INPUT: (H, W, 3) float32 in [0,1]                                             │
│    ↓                                                                             │
│  TILE LOOP (step by tile_size, overlap by padding):                             │
│    ├─ Extract patch with padding (clamped to bounds)                            │
│    ├─ Transpose HWC → NCHW, add batch: (1, 3, ph, pw)                          │
│    ├─ backend.run({"input": patch_t}, key) → {output_name: ndarray}             │
│    ├─ Transpose NCHW → HWC: (ph*scale, pw*scale, 3)                            │
│    └─ Accumulate with weight matrix (1.0 per contribution)                      │
│    ↓                                                                             │
│  STITCH: Normalize overlapping regions (divide by weight)                        │
│  CLIP: np.clip(output, 0.0, 1.0)                                               │
│    ↓                                                                             │
│  OUTPUT: (H*scale, W*scale, 3) float32 in [0,1]                                │
│                                                                                 │
│  NO SEAMS: Weighted averaging handles overlap perfectly                         │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────────────────────────┐
│ CPUBACKEND INPUT NAME REMAPPING (_remap_inputs)                                  │
├──────────────────────────────────────────────────────────────────────────────────┤
│                                                                                  │
│  Problem: Community ONNX models use arbitrary input names                        │
│  ├─ Real-ESRGAN exports: "input", "lq"                                          │
│  ├─ PyTorch common: "input.1"                                                   │
│  └─ Anime4K may use: custom names                                               │
│                                                                                  │
│  Solution: Auto-remap by position (if names don't match)                        │
│  └─ Caller always uses: {"input": tensor}                                       │
│  └─ Backend maps: tensor → model's 1st input (regardless of name)               │
│                                                                                  │
│  Result: Filters work with any ONNX regardless of I/O names                     │
│                                                                                  │
└──────────────────────────────────────────────────────────────────────────────────┘
