## 1. 副本选择弹窗（Variant Picker Sheet）

### 触发条件

对存在 ≥ 2 个副本的视频执行**文件级操作**时弹出：删除、永久删除、重命名、移动到、在 Finder 中显示。

### 布局（560pt 宽，自适应高）

```
┌──────────────────────────────────────────────────────────┐
│  删除副本                                          [✕]   │ ← 标题栏，48pt
├──────────────────────────────────────────────────────────┤
│  「这部影片在 3 个位置都有副本，请选择此次删除的对象」       │ ← 说明文字，type.callout
├──────────────────────────────────────────────────────────┤
│  ☑  [缩略图] /Movies/复仇者联盟.mkv           本地  ●   │ ← 副本行（52pt 高）
│              4.2 GB · 2160p · MKV                      │   ● = 在线状态点
│                                                         │
│  ☑  [缩略图] NAS/影视/复仇者联盟.mkv           NAS  ●   │
│              4.2 GB · 2160p · MKV                      │
│                                                         │
│  ☐  [缩略图] iCloud/Movies/...               iCloud  ○ │ ← 灰显行：操作不支持
│              「iCloud Drive 此文件暂不可用」             │   ○ = 离线
├──────────────────────────────────────────────────────────┤
│  ☐ 同时从媒体库移除（不保留记录）                          │ ← 仅删除操作可见
├──────────────────────────────────────────────────────────┤
│  [全选可执行]  [仅主副本]  [仅本地]                       │ ← 快捷模式按钮
├──────────────────────────────────────────────────────────┤
│                              [取消]  [删除 2 个副本]     │ ← 底部按钮
└──────────────────────────────────────────────────────────┘
```

### 副本行状态

| 状态 | 视觉 | 说明 |
|------|------|------|
| 可用 + 在线 | 正常行，绿色状态点 | 可勾选 |
| 可用 + 离线 | 正常行，灰色状态点 | 可勾选，操作时提示"该副本暂不可达" |
| 操作不支持 | 行整体 opacity(0.4)，右侧红色原因文字 | 不可勾选 |
| 主副本 | 左侧显示「主」徽章（accent 色） | 默认勾选 |

### 操作默认策略

| ⌘ 快捷键 | 操作 | 默认勾选 | 特殊规则 |
|---------|------|---------|---------|
| `⌘⌫` | 移到回收站 | 主副本 | 可改选 |
| `⌘⇧⌫` | 永久删除 | 无（强制手动勾选）| 底部显示红色警告 |
| `⌘L` | 重命名 | 主副本 | 单选，不允许跨副本批量 |
| `⌘⌥M` | 移动到 | 本地副本 | 网盘副本自动灰显 |
| `⌘R` | Finder 中显示 | 主副本 | 不弹窗，直接执行 |

### 动效

- 弹出：scale(0.96) + opacity，animation.modal
- 关闭：反向

## 2. 删除安全网 Toast

### 流程

```
⌘⌫ 按下
    │
    ├─ 选中 1 个文件 ──→ 立即移到回收站
    │                        ↓
    │              顶部 Toast（5s）
    │              「已移除《四月是你的谎言 E01》· 撤销」
    │
    └─ 选中多个文件
            │
            ├─ ≤ 10 个 ──→ 立即执行 + Toast
            │              「已移除 5 个文件 · 撤销」
            │
            └─ > 10 个 ──→ 二次确认弹窗
                              显示前 5 个文件名 + "等共 N 个"
                              [取消]  [移到回收站]
                              ↓ 确认
                           执行 + Toast
```

### Toast 规格

```
┌─────────────────────────────────────────┐  ← 顶部居中，距离工具栏 12pt
│  🗑  已移除 5 个文件  ·  撤销            │  ← 圆角 full，blur 背景
└─────────────────────────────────────────┘
      ↑                    ↑
   type.callout         accent 色链接
```

- 宽度：auto（按内容），最大 400pt
- 高度：40pt
- 背景：NSVisualEffectView(.popover)
- 自动消失：5 秒，带进度条（底部 2pt，accent 色）
- 同时最多显示 1 条（新 Toast 替换旧 Toast）
- `⌘Z` 可撤销，等效于点击「撤销」

### 30 分钟历史栈

- `⌘K → 输入"最近删除"` 或 侧边栏 → 最近删除
- 显示 30 分钟内所有已删除文件，可逐条恢复

│                                     │
│  锐化                [●────────]   │
│  ● CAS                             │
│                                     │
│  插帧                [ ○        ]  │ ← 未下载：灰色 toggle
│  ○ RIFE（需下载 45MB）↓            │

### 滤镜行规格

- 行高：44pt
- 开关：`Toggle`，accent 色

- 滤镜名：type.callout
- 模型名：type.caption1，textSecondary

- 刷新频率：500ms
- GPU 占用：LinearProgressView，accent 色
- 帧延迟：同上，>200ms 橙色，>400ms 红色
- 温度：>85°C 橙色，>90°C 红色 + 震动提示

### 字幕列表行规格

- 行高：56pt
- 活跃行：accent 色左边框 3pt + stateSelected 背景
- 序号：type.caption1，textTertiary
- 时间码：hivTimecode，textSecondary
- 文字：type.callout，2 行（原文 + 译文）

### 波形 + 时间轴

- 字幕条：圆角 sm，accent 色填充
- 拖动起点/终点 → 修改时间码（±帧精度）
- 空白区段（无字幕）：半透明红色高亮（静默检测结果）
- 缩放：⌘+ / ⌘- 调整时间轴密度

## 9. 误聚类拆分流程

### 触发

角色详情页 → 「识别样本」Tab → 选中某张不属于该角色的片段

### 操作步骤

1. 在「识别样本」Tab 中，选中（⌘ 多选）错误的片段
2. 点击「这不是 [角色名]」按钮（红色）
3. 确认弹窗：「选中的 3 个片段将从 Tony Stark 中移除，并标记为负样本」
4. 执行后：片段消失，AI 模型记住负样本，命中率数字更新
5. 若移除的片段属于另一已知角色 → 询问「这是谁？」→ 命名弹窗
