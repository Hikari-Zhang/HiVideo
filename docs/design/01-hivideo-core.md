## 1. 启动屏（Launch Screen）

### 布局

```
┌─────────────────────────────────────────────┐
│                                             │
│                                             │
│              [HiVideo Logo]                 │  ← 居中，64×64pt，圆角 16pt
│           「打开就能用，看完就懂你」            │  ← type.title3, textSecondary
│                                             │
│  ┌──────────────────────────────────────┐   │
│  │  拖入视频文件或文件夹，即刻开始播放       │   │  ← 虚线边框区域，96pt 高
│  │          ⌘O 选择文件                  │   │  ← type.callout, textTertiary
│  └──────────────────────────────────────┘   │
│                                             │
│  最近播放                                    │  ← type.subheadline, textSecondary
│  ┌──────┐  ┌──────┐  ┌──────┐              │
│  │海报1 │  │海报2 │  │海报3 │              │  ← 3 张海报卡，80×120pt
│  │      │  │      │  │      │              │
│  └──────┘  └──────┘  └──────┘              │
│                                             │
└─────────────────────────────────────────────┘
```

### 元素清单

| 元素 | 规格 | 状态 |
|------|------|------|
| Logo | 64×64pt，圆角 16pt | 静态 |
| 品牌口号 | type.title3，textSecondary，居中 | 静态 |
| 拖放区 | 虚线边框（borderDefault，dash：6/4），圆角 lg，96pt 高 | 默认/拖入高亮（accent 色描边）|
| 最近播放标题 | type.subheadline，textSecondary | 有最近文件时显示 |
| 海报卡 | 80×120pt，圆角 md，3 张横排 | 点击直接播放 |
| 全空态 | 只显示 Logo + 拖放区，无最近播放 | 首次启动 |

### 交互

- 拖入视频文件/文件夹 → 立即打开播放器
- 点击拖放区 → `NSOpenPanel`（⌘O 等效）
- 点击最近海报卡 → 直接播放（若文件已移动则显示"文件已丢失"Toast）

## 2. 主窗口框架

### 布局

```
┌──────────┬─────────────────────────────┬──────────┐
│          │      Toolbar（42pt）         │          │
│          ├─────────────────────────────┤          │
│ Sidebar  │                             │  Detail  │
│ 240pt    │       Main Content          │  Panel   │
│(min 180) │         flex                │  320pt   │
│          │                             │ (可收起)  │
│          │                             │          │
└──────────┴─────────────────────────────┴──────────┘
```

### 工具栏（Toolbar）

| 位置 | 元素 | 说明 |
|------|------|------|
| 左 | 侧边栏收起按钮 | `sidebar.left` SF Symbol |
| 左 | 视图切换 SegmentedControl | 网格/列表/时间线，⌘1/2/3 |
| 中 | 搜索框 | `⌘F` 聚焦，占位符"搜索视频、角色、标签…" |
| 右 | 详情面板收起按钮 | `sidebar.right` SF Symbol |
| 右 | 添加文件夹按钮 | `folder.badge.plus` |

### 侧边栏分组结构

```
── 媒体库
   • 最近
   • 在看（badge：数字）
   • 全部视频
── AI 智能
   • 电影
   • 剧集
   • 动漫
   • 教程
   • 录像
── 角色 （可展开）
   • Tony Stark (12)
   • 未知角色 (3)
── 标签
   • [用户标签列表]
── 文件夹
   • /Movies  [•进度点]
   • NAS/影视
── 播放列表
```

- 侧边栏行高：32pt
- 分组标题：type.caption1，textTertiary，大写
- 行文字：type.callout
- 选中态：stateSelected 背景，accent 色文字
- 在线状态点（绿/灰）：8pt 圆，跟在节点/网盘条目右侧

## 3. 媒体库 · 网格视图

### 海报卡规格

```
┌─────────────────┐
│                 │
│      海报图       │  ← aspect-ratio 2:3 (160×240pt base)
│                 │
│    ▶ 0:32:15   │  ← 进度条叠层（底部 4pt 高，accent 色）
├─────────────────┤
│ 视频标题          │  ← type.subheadline，1行，lineLimit(1)
│ 2024 · 1080p    │  ← type.caption1，textSecondary
│               ③ │  ← 副本数徽章（≥2 个副本时显示）
└─────────────────┘
  ↑ 圆角 lg (12pt)
```

### 四档尺寸

| 尺寸档 | 海报宽×高 | 触发 | 快捷键 |
|-------|----------|------|-------|
| 小 | 120×180pt | 视图拖拽条 | `⌘-` |
| 中（默认） | 160×240pt | — | — |
| 大 | 200×300pt | — | `⌘+` |
| 超大 | 240×360pt | — | — |

### hover 态

- 海报轻微放大：scale(1.02)，animation.default
- 底部出现播放按钮叠层（play.circle.fill，56pt，白色 @70%）
- shadow 从 sm → md
- 3 秒后自动播放前 5 秒静音预览

### 批量选择

- 点击时按住 ⌘ / ⇧ 进入批量选择
- 选中卡片左上角显示蓝色勾选框
- 底部浮现批量操作栏（高 56pt，背景 surfaceElevated，模糊）

### 空态

```
[icon: photo.stack]（56pt，textTertiary）
「还没有视频」
「拖入文件夹开始整理，或点击添加」
[按钮：添加文件夹]
```

## 6. 视频详情面板

### 布局

```
┌────────────────────────────┐
│ [海报图 2:3]               │  ← 宽 280pt，圆角 lg，有阴影
│                            │
├────────────────────────────┤
│ 视频标题                    │  ← type.title3，2行
│ 2024 · 2小时13分 · 4K HDR  │  ← type.footnote，textSecondary
│ ★ ★ ★ ★ ☆（用户评分）       │
├──────┬──────┬──────┬───────┤
│ 简介 │ 副本 │ 摘要 │ 章节  │  ← Tab Bar
├────────────────────────────┤
│ Tab 内容区                  │
└────────────────────────────┘
```

### 简介 Tab

- 简介文字（来自 NFO / TMDB），可展开折叠
- 元数据：分辨率 / 帧率 / 视频编码 / 音频轨道 / 字幕轨道

### 副本 Tab

- 每个副本一行：路径 / 大小 / 来源图标（本地/NAS/iCloud）
- 在线状态点（绿/灰/红）
- 「设为主副本」按钮

### 摘要 Tab

- AI 生成的视频摘要文字
- 生成状态：未生成 → 「⌘U 生成摘要」按钮
- 章节列表（含时间戳，点击跳转）

### 章节 Tab

- 章节列表（自动识别 + 用户编辑）
- 每章节：缩略图 + 时间戳 + 标题

## 7. 播放器（沉浸式）

### 窗口

- 无边框（`.borderless` 窗口样式）
- 内容铺满窗口，背景纯黑
- 鼠标移动 → 显示控制条（动效：move from bottom + opacity）
- 2 秒无操作 → 隐藏控制条
- 播放完毕 → 保持控制条可见

### 控制条布局

```
┌──────────────────────────────────────────────────────┐  ← NSVisualEffectView(.hudWindow)
│  ┌──────────────────────────────────────────────┐    │  ← 进度条（4pt 高，hover 8pt）
│  └──────────────────────────────────────────────┘    │    已播：accent 色，未播：white@30%
│                                                      │    悬停显示时间预览图（96pt 宽）
│  ⏮  ⏪  ▶  ⏩  ⏭    00:32:15 / 02:13:47    🔈 ──  ⬛ 📷 ✨ ⛶  │
└──────────────────────────────────────────────────────┘
   ↑         ↑             ↑                  ↑
  上下集   快退5s 播放     音量               右侧工具组
                                        字幕/画中画/截图/画质/全屏
```

控制条高度：72pt（含内边距），距底部 16pt

### 右上角 HDR 标识

- 位置：右上角，距边缘 12pt
- 内容：「HDR」 / 「Dolby Vision」 / 「HLG」小圆角徽章
- 颜色：金色，type.caption2
- 鼠标靠近时隐藏（避免干扰）

### 进度条悬停预览

- 悬停 → 显示缩略图气泡（96pt 宽，浮于进度条上方）
- 时间码显示于气泡下方（hivTimecode）

## 8. ⌘K 命令面板

### 布局

```
┌──────────────────────────────────────┐ ← 居中浮层，max 640×480pt
│  ┌────────────────────────────────┐  │ ← NSVisualEffectView(.menu)
│  │ 🔍  搜索或输入命令…             │  │ ← 搜索栏，48pt 高
│  └────────────────────────────────┘  │
│  ─────────────────────────────────── │
│  最近使用                             │ ← 分组头（type.caption1，textTertiary）
│  ▷  继续播放「四月是你的谎言 E02」    │ ← 结果行（44pt 高）
│  ▷  生成字幕 (⌘J)                   │
│  ─────────────────────────────────── │
│  视频 (3)                            │
│  🎬  四月是你的谎言 S01 E01          │ ← 含海报缩略图（32×48pt）
│  🎬  复仇者联盟                      │
│  ─────────────────────────────────── │
│  操作                                │
│  ⚡  生成摘要 (⌘U)                   │
│  ⚡  画质增强 (⌘E)                   │
└──────────────────────────────────────┘
```

### 规格

- 背景：NSVisualEffectView(.menu)
- 圆角：radius.xl (18pt)
- 阴影：Shadow.lg
- 搜索框：48pt 高，type.body，borderDefault 底线
- 结果行：44pt 高，圆角 md，hover → stateHover
- 键盘导航：↑↓ 移动，Enter 执行，Esc 关闭

### 结果分组顺序

1. 最近使用（最多 5 条）
2. 视频（媒体库搜索）
3. 角色
4. 操作（功能命令）
5. 设置项

├──────────────────────────────────────────────┤
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐         │
│  │ 12   │ │ 46   │ │3h 24m│ │ 96%  │         │ ← 4 个 metric 卡

### Metric 卡规格

- 卡片：flex 等宽，圆角 lg，surfaceSecondary 背景
- 数字：hivMetric（28pt Rounded Bold），accent 色
- 标签：type.caption1，textSecondary

### Tab 导航

| Tab | 内容 |
|-----|------|
| 出场视频 | 3列视频海报网格，点击直接播放 |
| 片段时间轴 | 每部视频一行，进度条上标记出场时段 |
| 台词搜索 | 搜索框 + 台词片段列表（含时间戳）|
| 关联角色 | 同框频率排行，角色头像卡片 |
| 同演员作品 | 该演员参演的其他作品（来自媒体库）|
