# HiPixel · Web 界面设计规范

> 对应 DEV-PLAN Phase 0.5 §0.5.5 / 0.5.6  
> HiPixel Web 使用独立的紫色主题，与 HiVideo macOS 视觉区分。

---

## 0. HiPixel Web 设计 Token

### 主题色（区别于 HiVideo）

| Token | Light | Dark | 用途 |
|-------|-------|------|------|
| `hipixel.primary` | `#7C3AED` | `#8B5CF6` | 主按钮、强调 |
| `hipixel.primaryHover` | `#6D28D9` | `#7C3AED` | 主按钮 hover |
| `hipixel.accent` | `#A78BFA` | `#C4B5FD` | 高亮元素 |
| `hipixel.surface` | `#FAFAFA` | `#111827` | 页面背景 |
| `hipixel.card` | `#FFFFFF` | `#1F2937` | 卡片背景 |
| `hipixel.border` | `#E5E7EB` | `#374151` | 边框 |

### 字体

- 正文：Inter（Web），SF Pro（macOS WebView）
- 代码/路径：JetBrains Mono / SF Mono
- 字号系统：12/14/16/18/20/24/32/40pt

### 圆角

| Token | 值 | 用途 |
|-------|-----|------|
| `radius.sm` | 6px | 输入框、小按钮 |
| `radius.md` | 8px | 标准按钮 |
| `radius.lg` | 12px | 卡片 |
| `radius.xl` | 16px | 弹窗 |
| `radius.full` | 9999px | 标签胶囊、状态徽章 |

### 响应式断点

| 断点 | 宽度 | 布局变化 |
|------|------|---------|
| mobile | < 768px | 单列，预设卡横向滚动 |
| tablet | 768–1024px | 2 列预设卡 |
| desktop | > 1024px | 3 列预设卡（默认） |

### 预设卡规格（200pt 宽）

| 元素 | 规格 |
|------|------|
| 图标 | 48×48pt emoji 或 SVG 图标 |
| 标题 | 16pt，font-semibold |
| 描述 | 14pt，text-secondary，1 行 |
| 预计耗时 | 12pt，text-tertiary |
| 选择按钮 | 宽 100%，圆角 md |

### 拖放区状态

| 状态 | 视觉变化 |
|------|---------|

| 已上传 | 绿色勾选 + 文件名 + 大小，可点击重新选择 |

### CTA 按钮状态

| 状态 | 视觉 |
|------|------|
| 禁用（未上传或未选预设） | 灰色，disabled cursor，tooltip 提示原因 |
| 可用 | hipixel.primary，hover 加深 |
| 处理中（上传进度） | 进度条填充 |

## 3. 对比屏（Comparison Screen）

### 布局

```
┌─────────────────────────────────────────────────────────────┐
│  ← 返回队列    复仇者联盟_enhanced.mkv              [↓下载]  │
├──────────────────────────────────────┬──────────────────────┤
│                                      │  关键帧报告          │
│  ← 原片        |        增强版 →     │                      │
│                │ ←拖→               │  帧 1  00:01:23      │
│  [视频画面左半] │ [视频画面右半]       │  [缩略图]            │
│                │                    │  ▢ 超分区域（绿）     │
│                │                    │  ▢ 降噪区域（蓝）     │
│                │                    │                      │
│                │                    │  帧 2  00:04:51      │
│                │                    │  [缩略图]            │
│                │                    │  ▢ 超分区域          │
├──────────────────────────────────────┤                      │
│  ○──────────────────────────●──── │  帧 3  00:12:07      │
│  00:01:23                  22:14   │  [缩略图]            │
└──────────────────────────────────────┴──────────────────────┘
```

### 分割线拖动

- 分割线：2pt 宽，hipixel.primary 色，两端圆形手柄（24pt）
- 左半：原片视频（灰色水印「原片」）
- 右半：增强版视频（紫色水印「已增强」）
- 进度条同步：拖左侧 → 右侧自动跟随

### 关键帧报告侧栏（280pt 宽）

- 自动选 6-12 个差异最显著帧
- 每帧：缩略图（120×68pt）+ 时间码 + 标注色块说明
- 标注色规范：
  - 绿色框：超分辨率处理区域
  - 蓝色框：降噪处理区域
  - 黄色覆盖：上色处理区域（黑白转彩色）
- 点击帧缩略图 → 跳转到该时间点
